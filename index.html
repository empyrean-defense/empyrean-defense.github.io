About

Empyrean Defense is a modern warfare tower defense game where you build, upgrade, and customize defenses to hold back an enemy invasion. Learn abilities and skills, craft advanced ammunition, and gather resources on the battlefield to strengthen and expand your defense.

Status

v0.6.1 - QOL Improvements & Bug Fixes (January 17, 2026)

Status: 🟢 Live on Steam Playtest

Improvements

  • Reduced installation size from ~3GB → ~1GB
  • Improved Pillbox Site targeting accuracy by adjusting attack line-of-sight origin
  • Updated Site Menu descriptions for improved clarity
  • Updated mission and loading screen images
  • Added scrolling to armory description panel using controller right stick

Balance Changes

  • Increased the amount of rockets given on Graywake Reach from 600 → 1000

Bug Fixes

  • Fixed incorrect controller icon display for DualShock and DualSense controllers
  • Fixed an issue where attack range indicators could clip at extreme terrain elevation changes
  • Fixed an issue with confirming selected ability on roads, bridges, and water when using a controller
