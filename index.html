About

Empyrean Defense is a modern warfare tower defense game where you build, upgrade, and customize defenses to hold back an enemy invasion. Learn abilities and skills, craft advanced ammunition, and gather resources on the battlefield to strengthen and expand your defense.

Status

v0.6.2 - QOL Improvements & Bug Fixes (January 24, 2026)

Status: 🟢 Live on Steam Playtest

New Features

  • Added left click and drag for easier mouse map panning
  • Added character popup when building first site and performing first upgrade on Verdant Anchorage

Improvements

  • Increased coin and item drop sizes and timers to make it easier to see and pick up
  • Increased hitpoints bars for sites and enemies and scale to distance to make it easier to see
  • Increased Supply Drop crate size

Balance Changes

  • Reduced item drop rates and increased drop amounts for all enemies

Bug Fixes

  • Prevent camera control and using abilities after level loads in but before intro conversation starts
  • Fixed an issue on controller with picking up coins and items under water

Steam Integration

  • Added rich presence tokens for menu and mission status
