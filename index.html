About

Empyrean Defense is a modern warfare tower defense game where you build, upgrade, and customize defenses to hold back an enemy invasion. Learn abilities and skills, craft advanced ammunition, and gather resources on the battlefield to strengthen and expand your defense.

Status

v0.7.0 - Steam Deck Support, QoL Improvements & Bug Fixes (February 1, 2026)

Status: 🟢 Live on Steam Playtest

New Features

  • Added sound effects for skill up and reset skills actions in the skill tree
  • Added a red glow to site HP bars when below 30% HP
  • Added on-screen arrow indicators for:
    • Sites below 30% HP
    • Sites that have run out of ammo
    • Landed Supply Drops
    • Incoming boss units
    • Rare item drops
  • Added a side button on the abilities bar to toggle Night Vision Goggles for keyboard & mouse users (the toggle setting is still available in Settings)
  • Renamed Greenwood Shoreline to Brightwood Bay

Improvements

  • Split Display settings out of cloud saves and keep them user/device specific
  • Removed redundant item descriptions from bottom pickup notifications
  • Updated interface action font to better match the game's theme
  • Improved clarity of Power Meter used/available text indicators
  • Dynamically position Objectives and Enemy Info panels based on UI scale and panel visibility
  • Standardized sizes for enemy damage numbers and notification popups
  • Display site HP bars above other objects by default, with a new toggle option in Settings
  • Display next wave panels above other objects
  • Added scrolling support to the mission description panel on the realm map
  • Added support for holding the D-pad to quickly adjust market item quantities when using a controller
  • Added PS5, Steam, and Steam Deck controller glyphs
  • Improved Steam Input API handling to better identify connected controller types
  • Increased the maximum value of UI Scale setting
  • Increased UI component and font sizes across the game for better readability
  • Removed market item quantity text input boxes on Steam Deck
  • Slightly increased the size of quick action menu icons
  • Allow B / O / Esc to exit pause menu

Balance Changes

  • Removed the final two LATVs from the boss wave on Sidewinder Pass
  • Increased Rocket Post base damage from 200 -> 210
  • Reduced item drop amounts from Adv. Supply Drop
  • Increased the cost of skill points in the market from 5,000 → 10,000
  • Reduced the base cost of several power and economy sites:
    • Solar Array (300 → 200)
    • Wind Turbine (600 → 400)
    • Power Plant (1200 → 800)
    • Fabrication Facility (1600 → 1200)

Bug Fixes

  • Fixed an issue with the Inspect icon when inspecting items using a controller
  • Fixed multiple controller focus issues across all menu pages
  • Prevented pausing before mission intro dialogue appears
  • Fixed a performance issue related to in-game cursor icon updates
  • Fixed an issue where selling a Power site right before taking damage could cause double power loss
  • Fixed mouse rotation continuing after pausing and unpausing
  • Fixed centering issues with the quick action menu when using a controller
  • Fixed an issue when binding abilities or quick action slots to Reset to Defaults button binding
  • Fixed tooltips appearing behind initial tutorial dialogues on menu pages
  • Fixed an issue where market item quantities could be adjusted via D-pad even when the quantity was 1
