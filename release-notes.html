v0.2.0 - Harborview District (November 7, 2025)

Status: 🟢 Live on Steam Playtest

New Features

  • Added 6th campaign level: Harborview District

v0.1.2 - Log Exporting and Balance Changes (November 3, 2025)

New Features

  • Added logging and log export button to Settings for bug/crash reports
  • Added skip button to character dialogues

Balance Changes

  • Pillbox
    • Buff base damage from 40 -> 44
    • Nerf crit chance from 3% -> 2%
  • Rocket Strike Ability
    • Rockets now always travel the same distance for more consistent timing
  • Switched the positions of the Ability Chain and Triple Threat skills in the Skills Tree
