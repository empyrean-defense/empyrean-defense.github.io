Release Notes

v0.9.1 - Interface & Performance Improvements (February 22, 2026)

Status: 🟢 Live on Steam Playtest

New Features

  • Added progress bars to Economy Sites to better visualize resource production

Improvements

  • Improved performance and stability during extended play sessions
  • Improved UI readability with larger fonts across the top navigation menu, buttons, credits and briefing panels
  • Improved controller navigation
    • Map mission panel objectives and medals are now focusable when using a controller
    • Tooltips behave more consistently when navigating with a controller
  • Introduced a new Main Menu layout with an integrated Briefing Panel
  • Added new UI button effect with a sticky selected option for controller navigation
  • Added Armory enhancements including ground, naval, and airborne scenes for improved presentation
  • Added higher resolution medal and tutorial icons

Balance Changes

  • Repair Ability
    • Repair per tick reduced from 200 → 120
  • Firestorm (formerly Napalm Strike)
    • Damage per tick increased from 50 → 70
  • Wraith Turret
    • Damage per shot increased from 50 → 70
  • Rocket attacks
    • Blast radius increased slightly
  • Sidewinder Pass
    • Crystal objective reduced from 1000 → 800
  • Graywake Reach
    • Adjusted time requirements slightly for Silver and Gold medals

Bug Fixes

  • Fixed Site Menu not showing base Power and Economy stats
  • Fixed multiple UI focus issues, especially when using a controller or Steam Deck
  • Fixed issues where ammo drops failed to spawn
  • Fixed Support Sites incorrectly applying or removing bonuses during power outages
  • Fixed Founder Boosts displaying incorrectly in the post game screen
  • Fixed several stability issues caused by orphaned terrain objects

v0.9.0 - Landmarks, Performance and Stability Improvements (February 16, 2026)

New Features

  • Introduced landmarks as neutral targets, including new interactions and mission fail conditions
    • Added Chapel of the First Sovereign landmark to Graywake Reach
  • Added ability damage popups with accompanying icons for clearer combat feedback
  • Abilities can now interact with sites during Mission Prep (before Wave 1 begins)
  • World repair and shield abilities now affect landmarks
  • Added a controller target icon for clearer target selection
  • Added a loss reason indicator when failing due to landmark destruction
  • Supply drop crates now auto-remove after one minute if uncollected
  • Added a dedicated boss icon for improved readability

Improvements

  • Improved item drop cooldown indicators with clearer visuals and background contrast
  • Increased font and icon sizes in the Site Menu right panel for better readability
  • Improved controller navigation and focus behavior across menus and UI panels
  • Power meter now appears earlier if the player owns a power related site
  • Improved ability targeting and AoE placement on uneven terrain
  • Increased decal height for AoE hover indicators to better handle elevation changes
  • Enemy info panel now also displays landmark details when applicable
  • Added landmark damage edge indicators for clearer situational awareness
  • Enemies now prioritize landmarks when appropriate
  • Improved visual clarity of circular menu buttons with updated fonts
  • Reduced UI tooltip flicker when navigating between menu pages

Balance Changes

  • Updated enemy targeting logic so enemies can engage both sites and landmarks
  • Adjusted large AoE abilities to rely on terrain based targeting for consistency
  • Reduced enemy soldier LOD bias to improve performance during large engagements
  • Improved explosion effect scaling for better visual feedback

Bug Fixes

  • Fixed save files failing to load when rank data exceeded the current max rank
  • Fixed demo save data incorrectly carrying over into the full game
  • Fixed controller and mouse input conflicts causing unintended camera panning
  • Fixed multiple controller focus issues across pause menus, medal containers, and play menus
  • Fixed landmark selection not properly updating the info panel
  • Fixed supply crate indicators persisting after the crate expired
  • Fixed pause flow when losing a mission due to landmark destruction
  • Fixed several tooltip positioning and rendering issues
  • Fixed post game menu animation issues
  • Removed unused assets and improved memory cleanup during loading and pause screens

v0.8.0 - Save Slots, Onboarding & Performance (February 8, 2026)

New Features

  • Added an onboarding checklist for new recruits to better familiarize them with the game menu and core mechanics
  • Added multiple game save slots, and the game menu quit button now provides an option to return to the main menu
  • Added enemy and site overlay shaders that trigger on damaging hits and abilities
  • Added Rank 2 Fire and Ice skill: boosts the Firestorm ability's damage by 25% and increases the effectiveness of the Blizzard ability's slow by 25%

Improvements

  • Increased initial camera rotation and movement speed slightly
  • The quick actions menu now reappears and highlights the site after closing site menu if the cursor is still hovering over it
  • Major performance enhancements to:
    • Military sites and enemies particle systems
    • Plasma Gun site
    • Reduced mesh counts across numerous models
    • Cache additional game menu resources for faster page loading
  • Increased dialogue font size and split up longer conversations for better readability
  • Moved game menu page intro dialogues to optional tutorial feature on each page
  • Added character popups for checklist completions and first-time game menu page visits

Balance Changes

  • Removed ability requirements from some skills

Bug Fixes

  • Fixed an issue where mission difficulty did not scale boss subcomponents hitpoints
  • Fixed an issue where repair drones did not trigger on pre-built damaged sites
  • Fixed an issue where the last selected map mission was not focused when the active input changed and the mission panel was closed
  • Fixed an issue with ammo crafting which allowed players to craft ammo that ran out of resources when crafting a previous different ammo type
  • Fixed an issue where Night Vision goggles toggle appeared incorrectly in the abilities side menu
  • Fixed an issue where out of ammo edge screen notifications could persist for certain ammo types

v0.7.0 - Steam Deck Support, QoL Improvements & Bug Fixes (February 1, 2026)

  • Standardized sizes for enemy damage numbers and notification popups

  • Increased Rocket Post base damage from 200 -> 210
  • Reduced item drop amounts from Adv. Supply Drop

    • Solar Array (300 → 200)
    • Wind Turbine (600 → 400)
    • Power Plant (1200 → 800)
    • Fabrication Facility (1600 → 1200)

Bug Fixes

  • Fixed an issue with the Inspect icon when inspecting items using a controller
  • Fixed multiple controller focus issues across all menu pages
  • Prevented pausing before mission intro dialogue appears
  • Fixed a performance issue related to in-game cursor icon updates
  • Fixed an issue where selling a Power site right before taking damage could cause double power loss
  • Fixed mouse rotation continuing after pausing and unpausing
  • Fixed centering issues with the quick action menu when using a controller
  • Fixed an issue when binding abilities or quick action slots to Reset to Defaults button binding
  • Fixed tooltips appearing behind initial tutorial dialogues on menu pages
  • Fixed an issue where market item quantities could be adjusted via D-pad even when the quantity was 1
