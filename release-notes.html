Release Notes

v0.4.1 - Controller Improvements (November 29, 2025)

Status: 🟢 Live on Steam Playtest

New Features

  • Added Pause When Unfocused setting (default to true) that will pause the game when the window loses focus or the Steam overlay is actived
  • If using a controller, automatically pause the game if the controller disconnects

Bug Fixes

  • Add controller hotkey for Reset To Defaults button in settings pages
  • Fix the rotation of build sites on Greenwood Shoreline

v0.4.0 - Rolling Hills (November 19, 2025)

New Features

  • Added 8th campaign level: Rolling Hills

Balance Changes

  • Buff IFV
    • Increase hitpoints from 3000 -> 3500
    • Increase damage from 50 -> 100
    • Increase range from 40 -> 45
    • Increase armor from 40% -> 45%
  • Increase Pillbox damage from 44 -> 45
  • Increase power usage of Field Tent from 200 -> 400

v0.3.0 - Dusthorn Canyon (November 9, 2025)

New Features

  • Added 7th campaign level: Dusthorn Canyon

Balance Changes

  • Remove most APCs from Harborview District
  • Reduce resources needed to craft Rockets and Flak Shells
  • Reduce credits given by Hidden Caches from 1000 -> 500
  • Add 200 extra starting credits on Verdant Anchorage

Bug Fixes

  • Fix issue with Flak Cannons doing double damage

v0.2.0 - Harborview District (November 7, 2025)

New Features

  • Added 6th campaign level: Harborview District

v0.1.2 - Log Exporting and Balance Changes (November 3, 2025)

New Features

  • Added logging and log export button to Settings for bug/crash reports
  • Added skip button to character dialogues

Balance Changes

  • Pillbox
    • Buff base damage from 40 -> 44
    • Nerf crit chance from 3% -> 2%
  • Rocket Strike Ability
    • Rockets now always travel the same distance for more consistent timing
  • Switched the positions of the Ability Chain and Triple Threat skills in the Skills Tree
