Release Notes

v0.6.1 - QOL Improvements & Bug Fixes (January 17, 2026)

Status: 🟢 Live on Steam Playtest

Improvements

  • Reduced installation size from ~3GB → ~1GB
  • Improved Pillbox Site targeting accuracy by adjusting attack line-of-sight origin
  • Updated Site Menu descriptions for improved clarity
  • Updated mission and loading screen images
  • Added scrolling to armory description panel using controller right stick

Balance Changes

  • Increased the amount of rockets given on Graywake Reach from 600 → 1000

Bug Fixes

  • Fixed incorrect controller icon display for DualShock and DualSense controllers
  • Fixed an issue where attack range indicators could clip at extreme terrain elevation changes
  • Fixed an issue with confirming selected ability on roads, bridges, and water when using a controller

v0.6.0 - SAM Launcher & Supply Drop (January 10, 2026)

New Features

  • Added SAM Launcher boss to Sidewinder Pass
  • Added boss and resources icons to map flags
  • Added Supply Drop ability
  • Added Advanced Logistics skill

Bug Fixes

  • Fixed targeting issue with enemy subcomponents
  • Fixed issue with ability bar interactions with picked up abilities
  • Fixed issue with Assault Rifle damage bonus

v0.5.2 - More Equipment (January 3, 2026)

New Features

  • Added Service Pistol to the Market (1,500 tokens)
    • Increases site and ability damage by 2%
  • Added Service Rifle to the Market (5,000 tokens)
    • Increases site and ability damage by 3%
  • Added Assault Rifle to the Market (10,000 tokens)
    • Increases site and ability damage by 5%
  • Added Field Logistics Kit to the Market (5,000 tokens)
    • Reduces site build and upgrade costs by 3%
  • Added Seed Capital to the Market (10,000 tokens)
    • Grants an additional 5% starting credits at the beginning of each mission
  • Added Power Cell to the Market (5,000 tokens)
    • Lowers energy usage of all sites by 5%

v0.5.1 - Night Vision Goggles (January 1, 2026)

New Features

  • Added Night Vision Goggles to the Market (1,000 tokens)
    • Used for night missions with low visibility

Bug Fixes

  • Fix issue with enemy subcomponents hitpoints not respecting mission difficulty

v0.5.0 - Azure Run (December 28, 2025)

New Features

  • Added 9th campaign level: Azure Run
  • Added Day/Night phases
  • Prevent Solar Arrays from providing power on night missions
  • Better environment fog effects
  • Remove fog toggle option in Settings
  • Added environment brightness option in Settings
  • Added a Next Wave indicator for each path, showing each enemy unit/amount expected in the next wave
  • Added option in Settings to toggle air path clouds
  • Added first boss and boss icons to related UI elements

Bug Fixes

  • Fix issue with persisting global attack prioritization setting

v0.4.2 - UX Improvements and Tier 2 Site Balance Changes (December 3, 2025)

New Features

  • New Damage/Crit popups
  • Added hotkey and icon for quitting the game from the play menu using a controller
  • Added dialogue container mission markers for better user experience during mission intros

Balance Changes

  • Nerf Missile Launcher Racking System upgrade from 50% → 15%
  • Increase Tesla Coil damage from 20 → 50
  • Increase Plasma Gun damage from 100 → 150

Bug Fixes

  • Fix issue with Infinite Reserves (Tier 1) skill showing infinite icons for Tier 2/3 sites
  • Fix issue with hitpoints bars color being affected by range ring decals
  • Fix issue with Tesla Coil damage sparks lagging behind units
  • Fix issue with buying items in the market with the Wolf of Wall Street skill learned

v0.4.1 - Controller Improvements (November 29, 2025)

Bug Fixes

  • Fix the rotation of build sites on Greenwood Shoreline
